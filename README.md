# Hôtel Ahoefa – King Salomon Garden (site vitrine)

Site vitrine en un seul fichier HTML (`index.html`) : photos, CSS et contenu sont intégrés.

## Publier sur GitHub Pages
1. Créer un dépôt sur github.com (ex. `hotel-ahoefa`).
2. Envoyer `index.html` et `README.md` dans le dépôt.
3. Dans **Settings → Pages**, choisir la branche `main` et le dossier `/ (root)`.
4. Le site sera disponible à `https://VOTRE-NOM.github.io/hotel-ahoefa/`.
